# 🛒 Supermarket Sales Analysis Dashboard

## 📌 Project Overview

This project focuses on performing an in-depth analysis of supermarket sales data to extract meaningful business insights. The objective was to analyze revenue trends, product performance, branch-wise sales distribution, and customer purchasing behavior using modern data analytics and visualization tools.

The project integrates multiple tools and technologies to demonstrate end-to-end data analytics capabilities — from raw data processing to interactive business dashboards.

---

## 🎯 Business Objectives

- Analyze total revenue trends across branches
- Identify top-performing product categories
- Evaluate customer purchasing patterns
- Compare branch-wise performance
- Understand payment method distribution
- Generate actionable insights for business decision-making

---

## 🛠️ Tools & Technologies Used

- **Python** (Data Cleaning & Preprocessing)
- **Pandas & Matplotlib** (Data Analysis & Visualization)
- **MS Excel** (Initial Data Exploration & Formatting)
- **Power BI** (Interactive Dashboard Creation)
- **Tableau** (Advanced Visual Analytics & Reporting)

---

## 📊 Key Insights Derived

- Identified peak sales periods and revenue fluctuations
- Analyzed gender-based and branch-wise purchasing patterns
- Determined most profitable product categories
- Evaluated customer rating distribution
- Compared payment method usage trends

---

## 📂 Project Workflow

1. Data Collection
2. Data Cleaning using Python
3. Exploratory Data Analysis (EDA)
4. Visualization in Excel
5. Interactive Dashboard Development using Power BI & Tableau
6. Insight Extraction & Business Interpretation

---

## 📈 Dashboard Features

- Revenue Overview Panel
- Branch Performance Comparison
- Product Category Analysis
- Customer Segmentation Insights
- Payment Method Breakdown
- Dynamic Filters & Slicers
